# Gamefowl Pro

Open `index.html` in a browser.

## Health tab
- **Symptom Checker**: pick a body area, tick symptoms, get ranked possible causes with care steps and vet warnings. Save a check to a bird's log.
- **Bird Log**: per-bird (Band ID) photo timeline and treatment tracker (days, doses given, withdrawal end date).

Photos and logs are stored on the device (IndexedDB), not uploaded anywhere. Clearing browser data erases them.
Condition content is original guidance, not a veterinary diagnosis.
